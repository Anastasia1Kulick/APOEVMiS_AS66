# Сверка с заданием: лабораторная №3, вариант 12

| Требование | Реализация |
| --- | --- |
| Написать макроопределение | REMOVE_RUSSIAN_WORDS MACRO с четырьмя параметрами и ENDM в remove_russian_words.inc. |
| Реализовать обработку внутри МО | Сканирование, проверка букв, копирование и удаление находятся в теле макроса, без CALL процедуры обработки. |
| Удалить слова хотя бы с одним русским символом | Проверяются диапазон U+0410..U+044F и отдельные Ё/ё (U+0401/U+0451); смешанные слова удаляются целиком. |
| Слова разделены пробелами | Разделитель U+0020; пробелы сохраняются, никакая дополнительная нормализация не выполняется. |
| Проверить работоспособность МО | 3348 прямых тестов; в каждом два раскрытия макроса в одной процедуре. |
| Параметры и безопасное повторное раскрытие | Проверены входы в регистрах и памяти, совпадение входной/выходной длины, LOCAL-метки. |
| Проверка сохранности | Проверены регистры, баланс стека, новая длина, конечный ноль, число удалений, повторное применение и защитные элементы вокруг буфера. |
| Самостоятельная третья лабораторная | Ввод до Enter; точка обычная; лимит 100 символов и правило сдвига из ЛР2 не используются. |
| Ассемблерный проект | MASM x86, только KERNEL32.dll, без C/C++ runtime. |
| Отчёт | Титульный лист, вариант, листинги исходников, реальные скриншоты. |

Результаты проверки Debug / x86 и Release / x86:

- 314 сценариев программы на каждую конфигурацию: 628 суммарно.
- 8 тестов настоящего ReadConsoleW на каждую конфигурацию: 16 суммарно.
- 3348 прямых тестов МО: 6696 раскрытий/исполнений макроса.
- Всего 3992 тестовых сценария. Успешно.
- Проверены Ё/ё, оба регистра русского алфавита, границы диапазонов Unicode,
  латинские и украинские буквы, пунктуация, табуляции, пустые строки,
  лишние пробелы, повреждённый UTF-8 и увеличение буфера на длинных строках.
- Программа проверена на строках до 65536 символов, макрос - до 100000 символов.

Сохранение пробелов намеренное: например, hello мир test преобразуется в
hello  test с двумя пробелами, поскольку удаляется слово, а не его разделители.
Нормализация пробелов отдельно сформулирована в варианте 7 методички.
