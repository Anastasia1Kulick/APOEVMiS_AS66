# Лабораторная работа №3: макроопределения, вариант 12

Ярома А. И., группа АС-66.

## Задание

Из строки слов удалить слова, содержащие хотя бы один русский символ.
Слово - непустая последовательность символов между обычными пробелами (U+0020).
Русские буквы: А-Я, а-я, Ё, ё. Регистр не имеет значения.
Латинские, украинские, греческие буквы и другие символы сами по себе не являются
основанием для удаления. Если в смешанном слове есть русская буква, удаляется всё слово.

Пробелы сохраняются в исходном количестве и порядке: нормализация пробелов
относится к отдельному варианту 7, а не к этому заданию. Например:

- `hello мир test` -> `hello  test` (два пробела между оставшимися словами).
- `mixЯabc keep ёж 123.` -> ` keep  123.` (удалены два слова).
- `alpha beta 123.` -> строка без изменений.
- `привет` -> пустая строка.

## Запуск

Откройте `Lab3Variant12.sln` в обычной Visual Studio 2026.
Для MASM, линкера и Windows SDK нужна рабочая нагрузка
«Разработка классических приложений на C++»; исходников C/C++ в проекте нет.
Выберите Release / x86 и нажмите Ctrl+F5.
Также можно запустить `build_run.cmd`.

Введите одну строку и нажмите Enter. Точка - обычный символ, а не конец ввода.
Пустая строка допустима. Ограничение в 100 символов из второй лабораторной
сюда не переносится: входной буфер увеличивается через HeapReAlloc по мере
необходимости, с проверкой нехватки памяти и переполнения размера.

## Макроопределение

Файл `remove_russian_words.inc` содержит полноценное макроопределение:

```asm
REMOVE_RUSSIAN_WORDS MACRO pText:REQ, inLength:REQ, outLength:REQ, removedWords:REQ
    ; тело обработки, LOCAL-метки
ENDM
```

В `main.asm` оно вызывается так:

```asm
REMOVE_RUSSIAN_WORDS textPointer, charCount, charCount, removedCount
```

MASM подставляет тело макроса непосредственно в место вызова. Сам макрос
не вызывает процедуру обработки: весь алгоритм находится между MACRO и ENDM.
LOCAL делает метки уникальными для каждого раскрытия.

Параметры:

- pText - значение адреса массива Unicode DWORD (регистр или DWORD-переменная);
- inLength - число символов (регистр, DWORD-переменная или константа);
- outLength - новая длина, записываемая в DWORD-переменную;
- removedWords - число удалённых слов, записываемое в другую DWORD-переменную.

Выходные переменные должны быть отдельными именованными DWORD-переменными
(либо локальными EBP-relative), не находиться внутри текстового буфера.
outLength может совпадать с inLength. ESP-relative операнды не поддерживаются.
Макрос сохраняет регистры общего назначения; арифметические флаги не определены.
В буфере нужен один дополнительный DWORD для конечного нуля.

## Организация программы

- `main.asm`: ввод строки, вызов макроса, печать результата и освобождение памяти.
- `remove_russian_words.inc`: параметризованный макрос удаления слов.
- `unicode_io.asm` и `unicode_io.inc`: ассемблерный Unicode-ввод/вывод через Win32 API.

В консоли используется ReadConsoleW, при перенаправлении - UTF-8 через ReadFile.
Один Unicode-символ хранится в одном DWORD, поэтому русские буквы не разрываются
на байты. Пунктуация и табуляция не являются разделителями слов по условию;
разделитель - только обычный пробел. Некорректная кодировка вызывает сообщение об ошибке.

Макрос сжимает строку на месте за O(n), используя O(1) дополнительной памяти.
При ошибке ввода/выделения памяти программа возвращает 1, при успешной обработке - 0.
