# Лабораторная работа №1, вариант 12

Ярома А. И., группа АС-66.

Откройте `Lab1Variant12.sln` в Visual Studio с установленной рабочей
нагрузкой «Разработка классических приложений на C++».
Выберите Release / Win32 и нажмите Ctrl+F5.

В `main.cpp` находятся отдельные функции `ReplaceSpacesCpp` и
`ReplaceSpacesAsm`. Вторая содержит ассемблерную вставку MSVC `__asm`,
поэтому отдельный файл .asm для этой лабораторной не используется.
Платформа x64 не поддерживает эту вставку: нужна Win32 (x86).

Введите строку и нажмите Enter. Обычные пробелы заменяются настоящими
символами горизонтальной табуляции. Программа выводит результат обеих
функций, число замен и проверяет совпадение результатов.

Для сравнения скорости отдельно создаётся 1000 строк по 4096 символов
для каждой реализации. Каждый пятый символ тестовой строки - пробел.
Контрольная сумма накапливает количество замен в этом тесте.

Отчёт находится в соседней папке `../rep/report.pdf`.
