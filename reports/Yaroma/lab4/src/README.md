# Лабораторная работа №4, вариант 12

Ярома А. И., АС-66. Архитектура и программирование сопроцессора x87.
Источник: методичка, страницы 316-318, таблица 2.2, вариант 12.
Оба раздела объединены в одной программе и одном отчёте.

## Запуск в Visual Studio 2026

1. Откройте `Lab4Variant12.sln` в обычной Visual Studio с компонентом
   «Разработка классических приложений на C++» (содержит MASM).
2. Выберите `Release` и `x86`. В проекте этой платформе соответствует `Win32`.
3. Нажмите `Ctrl+F5`.
4. Введите раздел `1` или `2`, затем `x` и `y`, каждый на отдельной строке.
   Например: `1`, `3`, `0` дают результат `1.2727272727272727`.

Также можно запустить `build_run.cmd`: он соберёт Release / x86 и запустит программу.
Конфигурация Debug / x86 тоже поддерживается.

## Формулы

Входы: x и y. Результат обозначен r, чтобы не путать его с входным y.

| Условие | Результат r |
|---|---|
| x - y > 2 | (x*x - 4*y + 5) / (x*x + 2) |
| x - y < -4 | (2*x + y) / (3*x*x + 4) |
| -4 <= x - y <= 2 | x*x - 2*y + 3 |

Значения на обеих границах относятся к третьей ветви.
Знаменатели x*x + 2 и 3*x*x + 4 строго положительны.

## Два раздела

- Раздел 1: целые входы от -2147483648 до 2147483647. `EvaluateInteger`
  использует `FILD`, `FIADD`, `FISUB`, `FIMUL`, `FICOMP` и регистры x87.
  Частное вычисляется командой `FDIVP` и сохраняется как REAL8 без усечения.
- Раздел 2: конечные вещественные входы double. `EvaluateReal` использует
  `FLD`, `FADD`, `FSUB`, `FMUL`, `FCOMP`, `FDIVP`.
  Допускаются десятичная точка и экспоненциальная запись, например `-1.25e2`.

Каждая ветвь оформлена отдельной приватной процедурой в `variant12.asm`.
Вычисления выполняются с 64-разрядной мантиссой x87 и округлением к ближайшему.
Исходное управляющее слово восстанавливается. На входе и выходе вычислительных
функций стек x87 пуст. Промежуточные значения остаются в расширенном формате;
окончательный результат округляется до double и выводится с 17 значащими цифрами.

## Ввод и ошибки

Одно число занимает одну строку длиной до 255 байт. Вокруг числа допустимы
пробельные символы. Пустой ввод, посторонний суффикс, неверный раздел,
переполнение целого, NaN/Inf и переполнение результата отклоняются сообщением.
Если разбор слишком малого вещественного числа даёт ноль с ошибкой диапазона,
ввод отклоняется; представимые ненулевые субнормальные числа принимаются.
Код завершения: 0 при успехе, 1 при ошибке.

Все исходные файлы программы написаны на MASM. Windows API задаёт кодировку
консоли UTF-8; системная `msvcrt.dll` используется только для разбора чисел,
консольного ввода/вывода и завершения программы. Формулы и выбор ветвей
вычисляются ассемблерными процедурами x87. Файл `io_imports.def` создаёт
библиотеку импорта при сборке; дополнительная установка библиотек не требуется.
