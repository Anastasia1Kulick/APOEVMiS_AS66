# Соответствие заданию

Методичка, стр. 316-318: работа с сопроцессором, оба раздела одной работы.
В репозитории курса эта работа имеет номер 4.

| Требование | Реализация / проверка |
|---|---|
| Вариант 12 таблицы 2.2 | Три формулы в `src/variant12.asm`; выбор по x-y |
| Целочисленные команды сопроцессора | `EvaluateInteger`, FILD и FI-команды |
| Вещественные команды сопроцессора | `EvaluateReal`, FLD и F-команды |
| Отдельная функция | По одной вычислительной функции на каждый раздел |
| Каждая ветвь отдельной внутренней процедурой | IntAbove/Below/Middle и RealAbove/Below/Middle, PROC PRIVATE |
| Консольный ввод/вывод | `src/main.asm`, `src/numeric_io.asm` |
| Проверка всех условий | Три ветви обоих разделов, обе границы и соседние double |
| Общий отчёт | `rep/report.pdf`, общий титульный лист, два раздела, листинги и снимки |
| Отдельная лабораторная | Все файлы находятся в `reports/Yaroma/lab4` |

Частное не усекается: целочисленные входы не означают целый результат.
Знаменатели в варианте 12 не обращаются в ноль при вещественных x.
Сравнения выполняются в x87 через FICOMP/FCOMP, FNSTSW и SAHF.
Промежуточная арифметика не выполняется в 32-разрядных GPR, поэтому квадрат
крайнего signed int не переполняет целочисленный регистр процессора.
