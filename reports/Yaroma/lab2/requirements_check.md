# Сверка с заданием: лабораторная №2, вариант 12

| Требование | Реализация и проверка |
| --- | --- |
| Программа на ассемблере | main.asm и text_processing.asm; в проекте нет ClCompile и C/C++ исходников. |
| Ввод, условие, преобразование, печать - отдельные части | Последовательные вызовы ReadText, CheckConditionAsm, RotateLeftAsm, PrintText из ProgramMain. |
| Непустой текст, не более 100 символов | Лимит MAX_LENGTH EQU 100, проверены пустой ввод и границы 1, 2, 3, 99, 100, 101. |
| Точка завершает ввод и не входит в текст | Сравнение с точкой до записи в буфер; всё после первой точки игнорируется. |
| Условие варианта 12 | Считаются а-я, ё и 0-9; сравниваются количества. Нули равны, поэтому 0 = 0 допустимо. |
| При ложном условии не преобразовывать | Сообщение и выход без вызова RotateLeftAsm. |
| Недопустимый ввод не преобразовывать | Сообщения для пустого текста, превышения лимита, отсутствия точки и ошибок Unicode. |
| Правило 12: сдвиг на 3 позиции влево | Циклический сдвиг на 3 mod n, проверен также для коротких строк. |
| Пометка «с.к.» | Применяются CLD и REP MOVSD. |
| Проверка и обработка - процедуры | CheckConditionAsm PROC и RotateLeftAsm PROC. |
| Нет дополнительной памяти, зависящей от длины | Один исходный буфер постоянной ёмкости; сдвиг на месте; вспомогательные локальные данные фиксированного размера. |
| Нет глобальных переменных | Изменяемые данные - LOCAL; неизменяемые сообщения - .const. |
| Удобный интерфейс | Приглашение, условие, правило, счётчики, результат или причина отказа. |
| Отчёт | Титульный лист, вариант, полный листинг двух .asm, реальные скриншоты. |

Проверено в Visual Studio 2026, Debug / x86 и Release / x86:

- 366 сценариев перенаправленного ввода на каждую конфигурацию: 732 суммарно.
- 7 сценариев настоящего ReadConsoleW на каждую конфигурацию: 14 суммарно.
- 1010 прямых тестов процедур: длины 0..100, счётчики, неизменность входа при проверке,
  сдвиг и контрольные элементы вокруг буфера.
- Итого 1756 сценариев. Среди них русские буквы, ё, прописные буквы, цифры,
  пробелы, переносы, Unicode вне BMP, неверный UTF-8 и превышение лимита.
- Проверка таблицы импорта EXE: только KERNEL32.dll; CRT и C++ runtime отсутствуют.
- PE не содержит изменяемой секции .data или .bss; строки сообщений находятся в .rdata.

Перевод строки учитывается как символ текста. Ввод абв123. имеет длину 6,
а ввод абв123, Enter, точка - длину 7. Это соответствует определению текста
как последовательности символов до точки.
