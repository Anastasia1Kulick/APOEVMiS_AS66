# Лабораторная работа №2, вариант 12

Ярома А. И., группа АС-66.

Откройте `Lab2Variant12.sln` в обычной Visual Studio 2026.
Нужна рабочая нагрузка «Разработка классических приложений на C++».
Выберите Release / Win32 и нажмите Ctrl+F5.
MASM уже подключён в файле проекта.

Введите непустой текст не длиннее 100 символов, завершите точкой
и нажмите Enter. Точка не входит в текст.

Пример: `абв123.` -> `123абв`.
Пример: `ё1.` -> `1ё` (3 mod 2 = 1).
Пример: `аб12X.` -> `2Xаб1`.
Если ввести `аб1.`, условие не выполнится и строка не изменится.

Проверка условия и преобразование находятся в `text_processing.asm`:
`CheckConditionAsm` считает строчные русские буквы а-я, ё и цифры 0-9;
`RotateLeftAsm` выполняет циклический сдвиг с помощью `rep movsd`.
Ввод/вывод в `main.cpp` использует UTF-8. Один символ в рабочем буфере
представлен одним 32-битным кодом Unicode; поэтому русская буква считается
одним символом, а не двумя байтами UTF-8.

Размер рабочего буфера фиксирован (101 DWORD). Дополнительный буфер для
сдвига не создаётся; используется один регистр для сохраняемого символа.
Глобальных переменных нет. Равенство 0 = 0 считается выполнением условия.

При ошибке ввода программа возвращает код 1, при обработанном допустимом
тексте (в том числе при ложном условии) - 0.
