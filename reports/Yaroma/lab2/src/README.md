# Лабораторная работа №2, вариант 12

Ярома А. И., группа АС-66.

Программа полностью написана на MASM x86. Исходников C/C++ нет.
Ввод, проверка, преобразование и вывод выполняются ассемблерными процедурами.
Для обращения к консоли и файлам вызывается Win32 API из KERNEL32.dll.
C/C++ runtime не подключается.

## Запуск в Visual Studio

Откройте `Lab2Variant12.sln` в обычной Visual Studio 2026.
Для MASM и линкера нужна рабочая нагрузка «Разработка классических приложений на C++».
Выберите Release / x86 и нажмите Ctrl+F5.
На уровне проекта эта платформа называется Win32; в решении - x86.
Альтернативный запуск со сборкой: `build_run.cmd`.

Введите от 1 до 100 символов и точку, затем нажмите Enter.
Например, `абв123.` нужно вводить одной строкой: результат `123абв`.
Если нажать Enter до точки, перенос строки тоже станет символом текста.
Точка в текст не входит, символы после первой точки не обрабатываются.

## Условие и преобразование

Условие: количество строчных русских букв равно количеству цифр.
Учитываются а-я, ё и цифры 0-9. Другие символы разрешены, но не увеличивают счётчики.
При равенстве выполняется циклический сдвиг влево на три позиции.
Равенство 0 = 0 также удовлетворяет условию.

- `абв123.` -> `123абв`.
- `ё1.` -> `1ё`, так как 3 mod 2 = 1.
- `аб12X.` -> `2Xаб1`.
- `аб1.` -> сообщение о невыполнении условия, без преобразования.
- `.` или больше 100 символов -> сообщение о недопустимом тексте.

## Устройство программы

`main.asm` содержит точку входа `start`, последовательность этапов в `ProgramMain`,
ввод `ReadText` и печать `PrintText`. Консоль читается через `ReadConsoleW` (UTF-16),
перенаправленный ввод - через `ReadFile` (UTF-8). Повреждённые последовательности
Unicode отвергаются. CRLF считается одним переносом строки.

`text_processing.asm` содержит отдельные процедуры `CheckConditionAsm` и
`RotateLeftAsm`. Сдвиг использует `CLD` и `REP MOVSD`, как требует пометка «с.к.».
Преобразование выполняется непосредственно в исходном буфере, без второго массива.

Единственный текстовый буфер - локальный массив из 101 DWORD фиксированной
ёмкости. Каждый элемент хранит один символ Unicode. Все изменяемые данные
локальны; в `.const` находятся только неизменяемые тексты сообщений.
Вспомогательные буферы одного символа и печати числа имеют постоянный размер.
Рекурсии, динамического выделения памяти и стека, растущего с длиной текста, нет.

При ошибке ввода код завершения равен 1; для допустимого текста - 0,
включая случай невыполненного условия. Подробная сверка: `../requirements_check.md`.
Отчёт: `../rep/report.pdf`.
