# Лабораторная №1, вариант 5

Батулин Михаил, группа АС-66.

**Задание:** даны две строки. Совместить первую половину строки 1 с первой
половиной строки 2. Результат — конкатенация этих половин в исходном порядке.
Для нечётной длины берётся `floor(length / 2)` символов; средний символ
в первую половину не включается. Пробелы сохраняются, пустой ввод допустим.
Пример: `abcde` и `1234567` → `ab123`.

## Запуск

Открыть `Lab1Variant5.sln` в Visual Studio 2022/2026 с рабочей нагрузкой
«Разработка классических приложений на C++», выбрать **Release / Win32**,
нажать Ctrl+F5. Win32 обязателен: MSVC не поддерживает `__asm` для x64.
Проект выбирает v143 в VS 2022 и v145 в VS 2026.

Либо в cmd выполнить:

```bat
build_run.cmd
build_run.cmd --demo
build_run.cmd --test
build_run.cmd --benchmark
```

Без аргументов программа читает две полные строки, выводит результаты обеих
функций и запускает тесты и измерение времени. `--demo` показывает готовые
примеры, `--test` — 308 проверок, `--benchmark` — тесты и таблицу времени.
К любому режиму с аргументом можно добавить `--hold`, чтобы окно ждало Enter.

Консоль работает в Windows-1251: английские и русские буквы занимают по байту.
UTF-8, эмодзи и произвольный Unicode не поддерживаются. При перенаправлении
ввода файл должен быть в Windows-1251. Исходники сохранены в UTF-8, ключ
`/utf-8` относится к компиляции, а не к кодировке входных данных.

## Устройство программы

- `combine.cpp`, `combine.h`: отдельные функции C++ и MSVC x86 `__asm`.
- `main.cpp`: ввод/вывод, демонстрация, измерение времени.
- `tests.cpp`: фиксированные граничные примеры и 300 воспроизводимых случайных
  пар строк; проверяются обе функции, нулевой терминатор и защитный байт.

Выходной буфер имеет `n1/2 + n2/2 + 1` байт, не перекрывается со входом.
ASM использует ESI, EDI, ECX, CLD и REP MOVSB. Сложность O(n1/2+n2/2),
дополнительная память функций O(1), память результата O(n1/2+n2/2).

Время — медиана 9 серий после прогрева; порядок функций чередуется.
Создание строк, вычисление длин и выделение памяти исключены из замера.
Функции помечены `noinline`, результат читается в volatile-контрольную сумму.
Время включает одинаковые накладные расходы цикла, вызова и контрольной суммы.
Отношение C++/ASM больше 1 означает преимущество ASM в данном запуске.
Измерения зависят от процессора, оптимизации компилятора и нагрузки системы.
