# Лабораторная работа №3, вариант 6

Удаление всех обычных пробелов из строки. Реализация для macOS на Apple Silicon (ARM64); методичка ориентирована на Intel, поэтому использование ARM64 для этой работы нужно отдельно согласовать с преподавателем.

## Сборка и запуск

Из этой папки:

```sh
./build.sh
./build/lab3
```

Сценарий собирает программу и тесты, затем запускает тесты ассемблерного макроса и пользовательского интерфейса. Для сборки нужны Apple Clang, Python 3 и macOS ARM64.

Программа читает строку до Enter или EOF. Она удаляет байт обычного ASCII-пробела `0x20`; табуляция и неразрывный пробел сохраняются. Строка UTF-8 обрабатывается побайтово без повреждения многобайтовых символов.

## Файлы

- `remove_spaces.S` — макрос `.macro REMOVE_SPACES` / `.endm` и две обёртки с независимыми раскрытиями макроса. Макрос раскрывается ассемблером во время сборки и не является вызовом процедуры.
- `remove_spaces.h` — объявления интерфейса для C++.
- `main.cpp` — ввод, вызов обёртки и вывод результата.
- `tests.cpp`, `test_cli.py` — тесты обоих раскрытий и программы.
- `tests_first.cpp` — первый проверочный пример.
- `build.sh` — сборка и запуск тестов.

Макрос преобразует байтовый массив на месте и возвращает его новую длину; завершитель NUL не записывается. `std::string::resize` в C++ устанавливает фактический размер результата. Контрольные байты в тестах проверяют границы записи; санитайзеры C++ не инструментируют отдельные инструкции ассемблера.

Отчёт с результатом фактического запуска находится в `../rep/` в форматах DOCX и PDF. Архитектуру ARM64 для этой лабораторной нужно отдельно согласовать с преподавателем.
