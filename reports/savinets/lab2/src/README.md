# Лабораторная 2 — вариант 6 — Mac ARM64

Проверить, равны ли количества прописных латинских и прописных русских букв. Если равны, поменять регистр латинских букв. Пример: `AaБб.` → `aAБб`.

Ввод: от 1 до 100 кодовых точек Unicode, до первой точки. Точка в текст не входит. Ё считается прописной русской буквой. Равенство 0 = 0 удовлетворяет условию. Пустой текст, неверный UTF-8, отсутствие точки и превышение длины отклоняются.

## Запуск на Mac Apple Silicon

Нужны инструменты Apple Clang / Xcode Command Line Tools. Из папки проекта:

```sh
bash run_mac.command --demo
bash run_mac.command --test
bash run_mac.command
```

Сценарий собирает программу в `build/lab2` и запускает её. Без аргументов нужно ввести текст, например `AaБб.`, и нажать Enter.

## Файлы

- `src/main.cpp` — ввод UTF-8, контроль длины, вызовы процедур, вывод и тестовый стенд.
- `src/lab2_mac.S` — процедуры на ассемблере ARM64.
- `src/lab2.h` — объявления процедур с C ABI.
- `run_mac.command` — сборка и запуск.
- `results/` — журналы реальных запусков и скриншот результатов.
- `../rep/` — отчёт Word и PDF.

Текст хранится в фиксированном массиве из 101 элемента char32_t, по 4 байта на элемент. Процедуры изменяют его на месте, работают за O(n), используют O(1) дополнительной памяти. Изменяемых глобальных переменных нет. Динамические строки используются только в тестовых режимах.

## Ассемблер

Адрес передаётся через X0, длина — через X1. `check_condition` считает A–Z и А–Я плюс Ё; возвращает 1 при равенстве и 0 иначе. В `transform_text` команда EOR переключает бит 0x20 только у букв A–Z и a–z. Другие символы сохраняются.

Указатель сдвигается на 4 байта. Используются caller-saved регистры X0–X5. Процедуры завершаются командой RET.

Проверки: 11 контрольных примеров, 5050 случайных случаев, границы буфера, лимит длины и некорректный UTF-8. Запуск с ASan/UBSan прошёл; ассемблер не инструментируется, его записи проверяются также контрольными элементами по краям.
